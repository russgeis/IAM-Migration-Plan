# IAM-Migration-Plan
We migrated Technobiz AD. Implemented an automated user provisioning system integrated with TechnoBiz's HR database. This system will ensure that user access permissions are updated in real-time based on employment status changes. Additionally, a self-service portal will allow employees to request access changes with manager approval workflows.
